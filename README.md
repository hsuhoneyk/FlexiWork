# FlexiWork

A PHP and MySQL part-time job board designed to help students find and apply for suitable work.

## Contents

- PHP application source, styles, and image assets.
- `database/schema.sql` — schema-only database setup. Sample and user records were excluded.

## Run locally

1. Copy this folder into the web root of a local PHP environment such as XAMPP.
2. Create the `flexi_db` database and import `database/schema.sql` in MySQL.
3. Set the local connection values in `db.php` for your environment.
4. Open the app through the local web server.

This repository contains source code, not a hosted production service.
